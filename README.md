# 🚀 Carreira Tech - Assistente Inteligente de Carreira

Uma aplicação web interativa desenvolvida com **Streamlit** e **Google Gemini AI**, projetada para otimizar a criação de currículos, análise de perfil profissional e exportação automatizada em múltiplos formatos.

---

## 📌 Funcionalidades Principais

- **Análise Inteligente de Perfil:** Utilização de modelos LLM da Google para estruturação estratégica de trajetórias profissionais.
- **Exportação Multiformato:** Geração automatizada de documentos nos formatos **PDF** e **DOCX**.
- **Processamento de Documentos:** Suporte à leitura e manipulação de arquivos PDF, imagens e documentos Word.
- **Interface Intuitiva:** Experiência de uso fluida construída inteiramente em Streamlit.

---

## 🛠️ Tecnologias Utilizadas

| Categoria | Tecnologia |
| :--- | :--- |
| **Linguagem** | Python 3.x |
| **Interface Web** | Streamlit |
| **Inteligência Artificial** | Google GenAI API (Gemini) |
| **Geração de PDF** | ReportLab / PyPDF2 |
| **Processamento de Documentos** | python-docx / Pillow |
